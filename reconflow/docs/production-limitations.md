# Production limitations

This demo uses locally supplied CSV files and has no live bank API integration or independently verified settlement feed, so completeness and authenticity of source data cannot be guaranteed. Its matching, timing, fee, refund, and rounding rules are simplified and may not cover every processor-specific lifecycle, partial capture, chargeback, reversal, multi-currency, or settlement-batch edge case. It has no production database, role-based authorization, maker-checker approvals, encryption/key management, or compliance-grade immutable audit infrastructure.
